# ScopeShield Demo SOW — PixelPeak Studio x BrightKart Retail
# 14 clauses. Exclusions in §5.2 and §7.1 are the traps for the demo CSV.

# Section 1.1: Project Overview
BrightKart Retail hires PixelPeak Studio to design and build a marketing website for its flagship store launch. Fixed-scope website project.

# Section 2.1: Timeline
Project kickoff March 3, 2026. Final delivery April 11, 2026. Weekly demos on Fridays.

# Section 3.1: Deliverables — Marketing Pages
Studio will deliver a 5-page responsive React marketing site: Home, Catalog, Store Locator, About, Contact. Includes hero section with up to 3 revision rounds.

# Section 3.2: Deliverables — CMS
Studio will wire the 5 pages to a headless CMS (Sanity) so BrightKart staff can edit text and images without developer help.

# Section 3.3: Deliverables — Analytics
Studio will add privacy-friendly page-view analytics (Plausible) on all 5 pages.

# Section 4.1: Hourly Rate and Payment
Contracted rate is $60/hr for any approved change orders. Net-15 payment terms.

# Section 4.2: Revision Policy
Each page includes up to 3 client revision rounds. Rounds beyond 3 are billable at the contracted hourly rate.

# Section 5.1: Authentication Scope
Scope includes email/password login for store managers only (max 5 accounts). No customer accounts in v1.

# Section 5.2: Exclusions — Identity and Compliance
Single sign-on (SSO), OAuth with Google/Microsoft, multi-factor authentication, role-based access control beyond store-manager, and SOC2 audit logging are expressly excluded from this SOW and require a separate change order.

# Section 6.1: Content and Localisation
Scope includes English-language content only, provided by BrightKart by March 7, 2026.

# Section 7.1: Exclusions — Infrastructure and Localisation
Production DevOps, Kubernetes deployment, uptime SLAs, CDN configuration beyond defaults, and additional language packs (including Hindi, Tamil, or other locales) are expressly excluded and require a separate change order.

# Section 8.1: Acceptance Criteria
Client accepts delivery when all 5 pages render on Chrome/Safari mobile + desktop and CMS edits publish within 5 minutes.

# Section 9.1: Change Control
Any work outside Sections 3–4 requested via Slack, email, Jira, or verbally must be logged and priced in a written change order before work begins. Unapproved extra work is not billable.

# Section 9.2: Out-of-Scope Billing
Out-of-scope work performed without a signed change order may be invoiced at market rates if the Studio provides clause citation and effort evidence within 7 days.
